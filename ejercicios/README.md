# Banco de ejercicios

Aquí se van guardando, por tipo, todos los ejercicios que genera la tarea diaria (tests diarios y específicos).

Cada subcarpeta tiene:

- `ejercicios.md`: lectura cómoda en GitHub (enunciado, opciones, respuesta, truco, dificultad y, si lo hay, el dibujo).
- `ejercicios.json`: los mismos datos para el seguimiento (id, test, número, fecha, subtipo, dificultad, respuesta correcta…).
- `img/`: dibujos de los ejercicios con imagen (figuras, fichas de dominó, relojes y tartas).
- `tests/`: PDFs de los tests específicos de ese tipo.

Un ejercicio no se repite en el banco: su id depende de su texto, opciones y dibujo. Los tests anteriores al 7 de noviembre de 2026 no están aquí.
